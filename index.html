ATR过滤是什么？为什么要有这个过滤？

📐 ATR (Average True Range) — 平均真实振幅

ATR衡量的是 每根K线的平均波动幅度。Acct2用的是 14根 1h K线的ATR%（ATR除以当前价格）。

核心逻辑: 如果每小时K线平均波动 > 2%，说明市场处于 趋势/剧烈波动 状态。均值回归在这种环境里会失效 —— 你买了"便宜"，它还会继续跌。

ATR < 2% → 允许开仓
市场处于震荡/横盘
价格在区间内来回
触碰布林带下轨 = 超卖
均值回归策略有效
ATR > 2% → 跳过所有信号
市场处于单边趋势
"便宜"买入还会继续跌
RSI30只是趋势途中的短暂停留
均值回归会持续亏损
公式
True Range = max(High-Low, |High-PrevClose|, |Low-PrevClose|)
ATR = 最近14根K线的TR均值
ATR% = ATR / 当前价格 × 100

if ATR% > 2.0: 跳过此代币，不开仓
实际案例: 为什么10-24大跌日ATR没有拦截？
⚠️ ATR的盲点: 缓慢下跌趋势
10-24当天，BTC、SUI、XRP等每小时只下跌约 -1~1.5%，所以 ATR% ≈ 1.2-1.8%，低于2%阈值。
ATR过滤通过了，但这是一个持续多小时的单边下跌，均值回归策略集中亏损。
教训: ATR能拦截急跌（闪崩），但拦不住"温水煮青蛙式"的缓慢趋势。

ATR过滤会触发的场景 — 历史对比

📊 假设场景: 急跌日 ATR 会是多少？

以10-24市场急跌为例。当天BTC 4h跌幅约-4.5%，换算成1h约-1.5%/h。
但如果遇到像BTC在某些时候的急跌（1h内 -3~5%），ATR%会快速突破2%:

例：BTC从82000急跌到79000 (3.7%，1h内)
→ True Range 该小时 ≈ 3000点 = 3.7%
→ 14根均值若混入3-4根这样的蜡烛，ATR% 可达 2.5~3.5%
→ 过滤触发，Acct2 跳过所有信号，保住资金
